# **Directrices de UI/UX y Diseño Web: Hacke's Jobs 2.0**

*Guía de Estilo y Experiencia de Usuario para el SaaS Corporativo*

## **1\. Filosofía de Diseño**

---

El sistema debe proyectar **modernidad, confianza y sofisticación**. La interfaz se alejará de los esquemas genéricos de plataformas de empleo para adoptar un estilo limpio y minimalista, propio de una herramienta SaaS de alta gama.

* **Minimalismo Funcional:** Reducción de ruido visual. Cada elemento en pantalla debe tener un propósito claro.  
* **Estética de Logotipo:** Los iconos y elementos decorativos deben tener un acabado pulido, minimalista y geométrico, casi con la calidad de un logotipo independiente.

## **2\. Identidad Visual y Atmósfera**

---

| Elemento | Especificación |
| :---- | :---- |
| **Fotografía** | Estilo editorial/corporativo premium. Imágenes de ejecutivos jóvenes transmitiendo éxito y ambición. Iluminación suave y encuadres profesionales. |
| **Paleta de Colores** | Tonos neutros (blancos puros, grises suaves, negro profundo) con acentos en azul corporativo o colores de marca que evoquen tecnología y profesionalismo. |
| **Tipografía** | Sans-serif moderna (ej. Inter, Roboto o Montserrat). Pesos variados para jerarquía visual clara. Alta legibilidad en datos numéricos. |

## **3\. Arquitectura de Interacción (UX)**

---

La experiencia del usuario debe ser fluida, reduciendo la carga cognitiva del reclutador y del candidato.

* **Dashboard Centralizado:** Uso intensivo de *espacio negativo* para separar los indicadores clave de rendimiento (KPIs) y evitar la saturación visual.  
* **Optimización 4K:** Activos visuales y layouts preparados para pantallas de alta resolución, manteniendo la nitidez en cada detalle.  
* **Micro-interacciones:** Feedback visual inmediato al realizar acciones (mover un candidato en el Kanban, procesar un video de IA, etc.).

## **5\. Criterios de Calidad Visual**

* ---

  **Prohibido:** Imágenes de stock genéricas, degradados saturados, sombras paralelas excesivas o interfaces sobrecargadas de botones.  
* **Obligatorio:** Consistencia en el radio de las esquinas (border-radius), alineación milimétrica en grids y coherencia en el tamaño de las fuentes.
