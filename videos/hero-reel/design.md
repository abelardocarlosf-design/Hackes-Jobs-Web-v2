# Design — Hacke's Jobs · neural / aurora

Concepto: un hilo naranja atraviesa las cinco etapas y convierte un enjambre de
currículums en una contratación confirmada.

## Color
| Rol | Hex |
|---|---|
| Fondo (void) | `#05060B` |
| Superficie (ink) | `#0B0E1A` |
| Línea | `#1A1F33` |
| Acento único (signal) | `#FF7A1A` |
| Datos (synapse) | `#3B6BFF` |
| Aurora (uso escaso) | `#8B5CF6` |
| Texto | `#E6E9F2` / secundario `#8A90A6` |

## Tipografía
- Display: Unbounded 400 (titulares y cifras), tracking -0.04em.
- Cuerpo: Manrope 500–700.
- Datos/etiquetas: JetBrains Mono 400, mayúsculas, tracking 0.16em.

## Do / Don't
- Do: glows radiales localizados, retícula tenue, grano.
- Don't: gradientes lineales a pantalla completa, texto con gradiente, neón cian.
